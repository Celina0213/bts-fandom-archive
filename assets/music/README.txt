【本地音源目录】（仅本机使用，已 gitignore，不会上传 GitHub）

把音频文件放到本目录，命名必须与歌曲 ID 完全一致：

  spring-day.(mp3|m4a|flac|wav)  →  Spring Day
  i-need-u.(mp3|m4a|flac|wav)    →  I NEED U
  run.(mp3|m4a|flac|wav)         →  RUN
  bst.(mp3|m4a|flac|wav)         →  Blood Sweat & Tears
  dna.(mp3|m4a|flac|wav)         →  DNA

注意：
1. QQ 音乐客户端下载的 .mflac 是加密格式，浏览器无法播放，需要通用格式。
2. 文件放好后 Ctrl+F5 强刷页面，点歌曲会出现本地播放条（播放键+进度条）。
3. 只放自己合法获得的音频，本目录内容严禁提交或二次传播。
